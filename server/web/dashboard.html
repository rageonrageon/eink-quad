Timing

On battery the tablet sleeps and wakes every wake-up minutes to check for news; a button press wakes it at once. It stays awake (Wi-Fi on, instant updates) only while its battery voltage is above the stay awake value, which happens while charging. Set it to 3.8 to stay awake until the battery is about half empty. Live game refresh only applies while awake.

Each update is a partial refresh of only the corners that changed (no flashing). The full refresh flashes once to wipe ghosting. Quiet hours pause updates, e.g. 23-6.
